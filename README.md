Welcome to **CS 280 – Object-Oriented Programming**!

In this course you will learn how to think about software in terms of _objects_: things that hold data and behaviour together, talk to each other through clear interfaces, and can be extended and reused. Object-oriented programming is behind most of the software you use every day, from mobile apps to games to large business systems. Learning it well will change how you design every program you write from now on.

The course is hands-on. You learn programming by writing programs, so expect to write code every week. Don't be afraid to make mistakes; that is how everyone learns. Ask questions in class, during office hours, or by email. There are no stupid questions.

This repository is the home of the course. Here you will find course information, examples from lectures, and practice tasks.

Good luck, and enjoy the semester!

## Syllabus

### Course description

This course introduces the principles of object-oriented design and programming using **Java**: classes and objects, encapsulation, inheritance, polymorphism, and abstraction. Students learn to model real-world problems with objects, write clean and reusable code, and apply common design principles and patterns.

### Learning outcomes

By the end of the course, you should be able to:

1. Explain the core concepts of OOP: encapsulation, inheritance, polymorphism, and abstraction.
2. Design and implement Java classes with appropriate fields, methods, and constructors.
3. Build class hierarchies and use polymorphism to write flexible code.
4. Use interfaces and abstract classes to separate _what_ code does from _how_ it does it.
5. Implement `equals()`, `hashCode()`, and `Comparable` correctly, and work with the Java Collections Framework (`List`, `Set`, `Map`).
6. Handle errors with exceptions.
7. Apply basic design principles (SOLID) and common design patterns.
8. Read, test, and refactor object-oriented code.
